# apps/registry

`nc-apps`: çekirdeğe gömülen yerleşik uygulamaların listesi (`nc_apps::builtin()`). Çekirdek uygulama crate'lerine doğrudan değil yalnızca bu crate'e bağlanır; yeni yerleşik uygulama buraya eklenir. `ring0-fallback` özelliği uygulamaların Ring 0 gerçeklemelerinin derlenmesini belirler.
