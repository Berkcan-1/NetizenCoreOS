# ESKİ (kaldırıldı): NCBM yerel modül SDK'sı

Bu klasör, üçüncü taraf kodu Ring 0'da çalıştıran NCBM modeline aittir. **Çekirdekten kaldırıldı** (F-01'in kalıcı
çözümü: yüklenen uygulamalar YALNIZCA Ring 3'te çalışır). Burada yalnızca port referansı olarak tutulur.
Yeni uygulamalar için `sdk/ring3-sample` ve `sdk/build.sh` kullanılır.
