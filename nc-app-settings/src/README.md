# nc-app-settings/src

## lib.rs

SettingsApp: sayfa (page) ve imlecin ustunde oldugu oge (Hover) tutar. update, pointer'i sidebar_item, swatch ve accent_rect
dikdortgenleriyle karsilastirir; tikta ctx.settings.wallpaper veya accent'i degistirir. Yerlesim fonksiyonlari area
(icerik alani) ve unit'ten turetilir. draw_personalize duvar kagidi onizlemelerini gradyan olarak cizer; secili olanin
etrafina vurgu renginde cift halka koyar.
